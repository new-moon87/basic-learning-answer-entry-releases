# 기초학력 답안 자동 입력 — 배포

스캔한 기초학력 진단검사 답안지(PDF)를 읽어 나이스 답안일괄등록서식(엑셀)에 자동으로 입력해 주는 프로그램입니다.

## 다운로드

👉 **[최신 버전 다운로드](https://github.com/new-moon87/basic-learning-answer-entry-releases/releases/latest)** 페이지에서 `기초학력답안입력.exe` 를 받으세요. (약 400MB)

## 사용 방법

1. `기초학력답안입력.exe` 실행 — **첫 실행은 30초~1분쯤 걸립니다** (로딩 화면이 뜹니다)
2. 나이스에서 내려받은 답안일괄등록서식(.xlsx)과 스캔한 답안지 PDF 선택
3. [분석 시작] → 자동 인식 → 검수 → [엑셀 저장]

자세한 사용법은 프로그램 첫 실행 시 안내 창에 나옵니다.

## 알아두실 점

- **Windows 보호 경고(SmartScreen)**: 처음 실행하면 "Windows의 PC 보호" 창이 뜰 수 있습니다. **[추가 정보] → [실행]** 을 누르면 됩니다.
- **자동 업데이트**: 새 버전이 나오면 프로그램 안에 알림이 뜨고, 버튼 한 번으로 업데이트됩니다.
- **개인정보**: 학생 정보와 답안지는 컴퓨터 밖으로 전송되지 않습니다. 인식·입력 전 과정이 내 컴퓨터 안에서만 동작합니다.
